# 把语音控制台接到课程从臂

**第一次预约最值得带回来的东西，是这台从臂的校准信息、能独立量出误差的现场画面，以及一条有回执的小位移动作。** 目前网页和命令行的执行对象都是 MuJoCo。仓库已有拍摄真相机与登记实测结果的工具。要让网页控制真臂，还需实现串口执行、真相机坐标转换和故障处置三个接口。以下安排按两天准备，另留半天处理现场发现的问题。本文记录接入设计，当前项目独立真机验收为 0 回合。[执行入口](../arm_lab/__main__.py) · [已有硬件核查](real_commissioning.md) · [现场计分器](../arm_lab/field_acceptance.py)

## 现场布置和机位

| 位置 | 怎样摆 | 怎样判断够用 |
| --- | --- | --- |
| 桌面与底座 | 将底座刚性固定在平整桌面，标出原点、向前 +X、向左 +Y、向上 +Z。先选一个取料站和一个放料站，验证后再加第三站。贴哑光工位边框和刻度。 | 实测基座到各工位的坐标、台面高度和边界。夹爪在接近、横移、释放、撤离时都可达。机械臂、木块及电缆的扫掠范围避开桌沿、灯架、相机支架和人手。 |
| 测试物与旁观测量 | 先用一个轻型哑光红方块，量好边长。仿真用的是 24 mm 立方体。备直尺、角度尺、已量格距的棋盘格和一张空桌照片，侧面布置能看清离桌高度的刻度或见证相机。 | 固定相机能区分空桌、工位中心和贴边摆位。实际木块尺寸、质量、夹指垫和目标位置随回合登记。空桌与同色干扰物专用于检验误报。 |
| 固定相机，优先装好 | 用独立支架从上方朝下，靠近正俯视，显示完整 A/B/C 边界、校准标记和爪尖活动区域。拧紧支架，固定焦距、分辨率、曝光和补光设置。按现场镜头调高度，仿真镜头的高度和视场角不能给出现场安装距离。 | 退爪后目标轮廓能完整入框。实际走一遍空爪路径，记录哪里被前臂遮住。取空桌、中心、边缘、相似红物四组照片。几何标定和检测均用控制端真正消费的分辨率及裁切。 |
| 腕部相机，可选 | 先核对设备是否确实装有 USB 摄像机。固定在随爪刚性运动的部件上，斜向看指尖与退爪后的目标区；走线留出关节运动余量。 | 拍下接近、试抬、撤离后的画面。若爪尖挡住目标、方块被裁掉或失焦，腕部只作辅助观察。作为自动复核相机前需测内参及相机相对腕端的刚体变换，并对齐图像时间和关节位姿。 |
| 操作与监控 | 控制电脑在机械臂旁通过 USB 接总线和相机，远端浏览器看视频并提交通讯请求。现场人员能看到机械臂全身，也能操作课程设备指定的本地停止措施。 | 先在本机测，再测局域网。用共享视觉事件测实际画面延迟。麦克风录音使用浏览器认可的地址或 HTTPS，也可上传录音。网页心跳覆盖活动请求，真机停住持物后仍要在设备端监控。 |

固定相机的像素到毫米转换应先标定内参和畸变，再用底座坐标已知的标记求外参，或对固定视角直接标定**静置木块顶面**的平面映射。平面映射至少需四个分布在工位周围、无三点共线的点。桌面上的标记与木块顶面有高度差，需用已测外参补偿，或把标记垫到顶面等高。另留 A/B/C 中心和边缘点验算，以尺量真值统计每点 XY 误差及最大误差。相机、底座、分辨率、物块高度变化后复核。木块被抬起后，固定平面的映射已不适用。[现有仿真投影](../arm_lab/vision.py) · [腕部投影实现](../arm_lab/wrist_view.py) · [OpenCV 标定教程](https://docs.opencv.org/4.8.0/dc/d43/tutorial_camera_calibration_square_chess.html)

## 哪些配置可用，哪些需要开发

| 接入项 | 今天已有 | 登机前要改或实测的内容 |
| --- | --- | --- |
| 型号、串口、驱动和校准 | 课程配套程序按 SO-101 follower、Python 3.12、`lerobot[feetech]==0.6.1` 实现。语音项目的 uv 锁目前只含仿真、语音、数据工具。 | 核对设备标签、控制板、电机、供电及课程分配的校准标识。若设备实际型号与 SO-101 不符，先核对该型号对应的驱动、模型、单位和关节限制。Windows 设备管理器查看 USB 对应的 COM 号，记录校准 ID、文件版本、关节零位/符号及读回单位。沿用实验室已校准的这台臂。 |
| 真机动作后端 | `serve` 和 `run` 都构造 `Simulator`。规划输出 `steps`，其平移用 mm、转腕用 °。另行提供的课程 `so101_lab_new/control.py` 有独立键盘控制和 IK。 | 给网页的控制线程接一个独占串口的真机执行器，逐步执行校验后的动作，返回时间戳、实测位置、夹持证据和回执。与课程包中的 `--backend real --port <现场COM> --id <设备校准ID>` 区分，当前语音控制台没有这些真机参数。实测对齐 TCP（夹爪中心）、轴序、关节符号和限位。课程前五轴按度、夹爪开度为标定行程的 0–100。为 IK 明确转换米/毫米和度/弧度。 |
| 摄像头与视觉坐标 | 取证工具已支持 `--fixed-device`、可选 `--wrist-device`、`--backend dshow` 或 `msmf`。网页相机与当前投影读取仿真状态。 | 给控制链注入 USB 实拍源及标定文件，导入镜头内外参、工位轮廓、木块厚度和底座坐标。相机采入的 OpenCV BGR 帧要按检测器约定转 RGB。现场记录画面来源和采集时间。腕部未经标定时，自动复核只用已验证固定视角，遮挡则返回“未确认”。 |
| 工位、路线和限位 | `scene.py` 给出仿真工位、桌高和爪心偏移。`--keepouts` 读取底座坐标系、米单位的轴对齐障碍盒子。仿真用 8 mm 抓取准入、最多 6 mm 的微调。 | 示教各站上方、抓取、试抬、放下及撤离姿态。现场测桌面、支架和其他障碍，填障碍中心、半尺寸、保守余量，再接入真机路径预检。允许的单步增量、速度、抓取余量按独立测量重定。检测误差、机构重复误差与木块偏摆合计须小于实测夹爪可捕获余量。 |
| 夹爪、停止与恢复 | 仿真依靠双侧接触、夹爪开度、受限力矩和离桌反馈。实际课程控制观察量主要是关节位置。 | 到首次可信接触或异常时结束继续收紧，监测陈旧读数、停滞和报警并锁存。实测该驱动哪些负载/电流/错误字段能读、单位和更新率，再确定有证据的持握方法。低空试抬用独立画面验物块随爪运动。实现设备侧超时，覆盖网络断连及暂停后空闲持物；按现场托稳、释放程序恢复。报警不自动重发闭合、复位或重抓。若反馈尚不足，现场演示止于已验证的空爪动作。 |

官方文档将从臂类型列为 `so101_follower`，端口与设备校准 ID 绑定。v0.6.1 的 `SOFollower.connect(calibrate=False)` 仍调用 `configure()`，其中会写入驱动配置。盘点 COM 或用独立相机拍照时，不应把这条调用当成总线只读探针。首次只读取关节状态应使用实验室认可且确认没有配置写入的只读工具；若无此工具，先完成相机、场地和离线工作。需要用电时按现场流程托稳，启用已确认的课程控制入口。[LeRobot 官方 SO-101 安装、排障与校准](https://huggingface.co/docs/lerobot/so101) · [v0.6.1 从臂连接和配置源码](https://github.com/huggingface/lerobot/blob/v0.6.1/src/lerobot/robots/so_follower/so_follower.py) · [v0.6.1 配置字段](https://github.com/huggingface/lerobot/blob/v0.6.1/src/lerobot/robots/so_follower/config_so_follower.py)

## 两天准备和一次短预约

**第 1 天，在自己的 Windows 电脑上。** 从本仓库根目录用下面两条命令复现仿真环境和生成现场记录表。准备打印标记、测试物、量具及相机支架。向实验室确认设备型号、校准 ID、是否配腕部相机、是否提供课程包。若使用课程包，在它自己的目录中用 `uv venv --python 3.12 .venv`、`uv pip install --python .venv/Scripts/python.exe -r requirements.txt` 准备独立环境，再用 `.venv/Scripts/python.exe check_environment.py` 离线自检。先用已保存规划回复验 JSON 到回执的真机适配器草案，允许到达驱动的动作先记日志。此阶段可不开模型、不接设备。

~~~powershell
uv sync --frozen --extra voice --extra data
uv run --frozen --extra voice --extra data python -m arm_lab.field_acceptance template outputs/field/trials.csv
~~~

**第 2 天，建议预留 90 分钟。** 以下是待执行的时间规划。后一步所需条件没有验证时，优先保存前一步的实测结果。

| 分钟 | 现场实验 | 留下的证据与继续条件 |
| --- | --- | --- |
| 0–20 | 核对设备和校准、固定底座和相机；空桌、中心、边缘和同色干扰各拍一组。 | 记下 COM、校准 ID、相机索引、分辨率、实测工位和照明。找到可能跨站的误差或红色假目标时，先停在观察模式。 |
| 20–35 | 读回静止关节、核对数据刷新。托稳条件下按课程程序做空爪小幅正负位移，核对 TCP 和轴符号。测试本地暂停、取消剩余动作和空爪状态的客户端断连。 | 保存原始反馈、发出停止到实际停住的时刻、残余位移和最近一帧。未核实方向、净空或停止距离，留在单步本地控制。 |
| 35–55 | 完成登记表中 X/Y/Z 各 10 mm、转腕 +3°、−3°、+5°。先文字，再以同一条获准的语音测试检查前后画面。 | 用独立尺标/角度尺记录实际三轴位移、角度，记请求、计划、实测、读回与结束状态。原表移动误差按三维向量长度 ≤5 mm、腕角误差 ≤2° 计分，这只是课程计分线。 |
| 55–80 | 在前项和夹持条件满足时，先做一个低位有支撑的取放循环。验证初触后结束继续收紧、受控试抬后物体确实离桌、释放且爪已退开。逐步覆盖正常 A/B/C、目标遮挡、起点边缘。 | 每回合保存前后画面和回执，现场另记落点为 A/B/C、持物、区外或未知。边缘、遮挡或反馈不足时记录拒绝/未确认。遇报警或滑脱结束当回合。预约不足时保留待测行。 |
| 80–90 | 保存失败例，复拍现场标记，记录已验证与待验证的边界，按课程流程让设备回到可交接状态。 | 报告实测完成数、未测数、误报成功、终点误差和一次完整回合的证据。若真机后端仍未接入，课程键盘操作和人工摆拍均单独标注。 |

**有第 3 天时。** 只补第一次暴露的瓶颈。比如工位边缘易误放，可保留同一机位和门槛，用此前没调过的摆位做复测。若主要是语音方向混淆，复用相同场地采几句左右、数字、单位、否定词，记录转写、用户更正与规划结果。需要调用 Whisper、校方模型或 TTS 时按次确认。报告分别给出语音、视觉和运动的分母。

现场取证命令如下。示例中的 `0` 仅指已在现场人工确认的固定相机索引；如有腕机且索引已确认，增加 `--wrist-device 1`。已有采集程序独占摄像头时，先保存其视频，稍后用取证工具的 `--fixed-video` 离线取帧。每回合填入 `evidence` 路径，再运行计分器。完整登记表预留了 9 次搬运、3 次平移、3 次转腕。没有实测证据的行保持空白。[双视角取证与文件说明](field_cameras.md) · [视觉误检与边界误差](vision100.md)

~~~powershell
uv run --frozen --extra voice --extra data python -m arm_lab.field_cameras --fixed-device 0 --trial 1 --phase before --samples 3 --fps 3
uv run --frozen --extra voice --extra data python -m arm_lab.field_cameras --fixed-device 0 --trial 1 --phase after --samples 3 --fps 3
uv run --frozen --extra voice --extra data python -m arm_lab.field_acceptance score outputs/field/trials.csv --out outputs/field/score.json
~~~
