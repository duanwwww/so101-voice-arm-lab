# 项目总结与交接

这套课程原型让操作者看着 A/B/C 三个桌面工位，用中文指挥一台固定底座的 SO-101 仿真从臂。目标级指令可以指定“把红块从 A 搬到 B”，定量指令可以指定“向右移动两厘米”。操作者可以在同一个场地中继续说明、查询和暂停。当前可以演示完整仿真流程，真机部分已经准备了取证工具和实验表，尚无本组实体试验成绩。[工作流图、各节点验证与改进](workflow.md) · [带回执和双视角画面的演示视频](../results/safety/simulation_demo.mp4)

## 本项目完成的工作

| 环节 | 实现及证据 |
| --- | --- |
| 浏览器与语音 | 在 Windows 控制电脑接收录音、上传音频或文字。转写可编辑，模型调用按用途批准。进行中的查询、禁止、暂停与恢复由本地解释，下一条运动会等待操作者核对现场。[交互机制](deployment.md) |
| 指令与控制 | 设计有限动作 JSON、对话澄清、原话与场景一致性检查、路径预检、分段执行和失败回执。使用 100 条预先有答案的输入迭代提示词，用真实校方回复做配对评分和仿真重放。[实验与逐题结果](planner100_results.md) |
| 感知与运动 | 在模型中搭建双视角、已知工位、自由木块与夹爪接触，支持有界偏位修正、试抬、落位复核和遮挡时报告“未确认”。公开标注图负责检验误报，MuJoCo 物理状态负责检验实际运动和落位。[视觉实验](vision100.md) · [运动实验](control_iteration.md) |
| 工程交付 | 提供 uv 锁定依赖、离线启动入口、自动化测试、可回查的原始回复与图像指标。现场表分别记录目标、预期、实际读数、前后画面和失败原因。[组员启动说明](../README.md) · [真机交接与预约计划](hardware_handoff.md) |

采用了四类课程模块：语音交互、视觉感知、大模型推理与规划、模拟物理执行。与已有语言机器人系统相比，本项目的取舍是把小范围桌面控制做成可逐步核查的操作链。操作者能看到上条指令执行到了哪里，哪些语句需要补充，以及哪次放置因遮挡难以确认。[已有产品、论文、开源方案和方法对比](related_work.md)

## 结果怎样解释

四条既有合成录音在同一场地经真实 ASR、正常 HTTP 接口、本地规则、仿真和相机回执运行，共 3/4 达到预期。成功包括 1 次平移和 2 次原位处理；搬运句因目的地方向误听进入追问。单次搬运的澄清逻辑随后修复，另测由脚本模拟用户明确补答 B，系统在原场地完成搬运，三次物理采样均核实落位。补答后的成功单列。

当前默认语音已改为本地 SenseVoiceSmall INT8。同一批 24 段真人录音的字符错误率从历史 Whisper beam=1 的 20.51% 降到 10.67%，但两处方向词仍有误听。四条合成口令的搬运句也把“右边”写成了“右干”。替换后仍要在原始转写上检查方向、量纲和否定。[本轮语音与仿真验证](sensevoice.md)

留出动作题中，终选提示词精确生成参考控制 JSON 的比例为 27/42；与原版逐题比较，原版是 15/42。新版仍出现方向符号反转。控制器在这批留出输入中拦下全部 11 个含义错误的物理动作，同时也拦掉两个措辞明确、模型已答对的仿真任务。视觉在 100 张有红块的实拍图上有 67 张得到唯一正确候选。无红块的外部仿真图暴露了苹果、红碗等单个红色物体的混淆。预选 12 个仿真任务达到目标 10 个。各节点样本及判据不同，没有把这些数字相乘作为总成功率。[规划和执行](planner100_results.md) · [失败归因](planner100_failure_review.md)

适合本阶段的展示是一个清楚可辨的红块、三个已标定工位、远程发令和状态反馈。进入真实桌面后，优先核实目标身份、轴符号、物体偏位和夹住后的停收紧逻辑。没有独立证据时，结果记为“未确认”。第一次预约的 90 分钟安排、先测空爪停止再测低位单次抓放的继续条件，均写在真机手册里。[配置、场地、机位与实验清单](hardware_handoff.md)

## 共享版复现检查

在一个不含课程专用 Python 文件、未配置任何模型密钥的干净 Git 克隆中，默认自动选择独立的 MuJoCo 运动学实现。93 项自动化测试全部通过，读取已保存的终选版真实回复后再次运行 12 个预选任务，10 个达到目标。逐条初态核对、状态和成败与课程版一致。运动学有两处小的数值变化：P053 的三维位移误差从 0.227 mm 变为 0.198 mm，P072 第一步由 0.207 mm 变为 0.204 mm。原课程实验记录保留其原有实现和 91 项测试的结果。[独立实现](../arm_lab/kinematics.py) · [适配回归测试](../tests/test_kinematics.py) · [原实验记录](../results/safety/planner100/verification.json)

## 来源和贡献记录
